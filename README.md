# Lunaphase Games — Out of Line

Official studio and game landing page, hosted on GitHub Pages.

- **Live site:** https://lunaphasegames.github.io/
- **Steam:** https://store.steampowered.com/app/5169010/
- **Community:** https://discord.gg/uvZzBc7vxM

## Files
- `index.html` — studio/game landing page and SEO metadata
- `styles.css` — responsive visual system and layouts
- `script.js` — mobile navigation and dynamic copyright year
- `404.html` — custom not-found page
- `images/` — existing game artwork, capsules, favicon and source materials

The site is plain static HTML, CSS, and JavaScript; no package manager or build process is required. Existing artwork in `images/` is reused directly.

## GitHub Pages
In repository Settings → Pages, use **Deploy from a branch**, select `main` and `/(root)`. Commits to `main` will publish automatically. Confirm this publishing source is selected before expecting updates to appear.

## Content
The game is presented as **Out of Line**, per the studio's naming direction. The GDD is retained in the repository's images/source-material folder but is not linked from the public website. Before public release, confirm Steam page visibility, supported platforms, release timing, and any wishlist/demo wording.
